# Day 4 - Composition vs Inheritance

## Topics Covered
- Inheritance
- Composition
- IS-A relationship
- HAS-A relationship
- Composition over inheritance principle

## Programs

1. inheritance_vehicle_system.py
   - Vehicle hierarchy using inheritance

2. composition_computer_system.py
   - Computer system using composition

3. smartphone_design.py
   - Hybrid design using inheritance + composition

## Key Learning

Inheritance is used when one class is a specialized version of another class.

Composition is used when one class contains objects of other classes.
